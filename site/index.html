Comment importer le fichier dans mon navigateur ?
  • Firefox : Ctrl+Maj+O (Bibliothèque) → Importation et sauvegarde → Importer des marque-pages au format HTML.
  • Chrome, Brave, Vivaldi : ouvrir chrome://bookmarks → menu ⋮ → Importer les favoris.
  • Edge : ouvrir edge://favorites → menu … → Importer des favoris → Fichier HTML des favoris.
  • Opera : ouvrir opera://settings/importData → Fichier HTML des signets.
  • Safari : Fichier → Importer depuis → Fichier HTML de signets.

Les liens arrivent dans un dossier à part : vos favoris existants ne sont pas modifiés. Pour une mise à jour, supprimez l'ancien dossier puis réimportez.
